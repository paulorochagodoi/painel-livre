# Dock

Barra inferior fixa com início, temperatura de cada lado e atalhos rápidos.

**Fornece:** `store`.

- Esquerda: início e temperatura do motorista (‹ 22,0° ›). Direita: temperatura do passageiro.
- Centro: climatização, banco do motorista (cicla aquecimento 1–3), desembaçador, telefone, apps, ajustes, volume/mídia.
- Botões de 56px (`touch-min`), raio `radius-md`. Ativo em `accent-soft` / `accent`; banco aquecendo em `heat-soft` / `heat`.
